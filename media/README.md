# Media intake

Drop real photos and screenshots in here. **Nothing in this folder is served by the site** —
it is the staging area between "Ashton has the file" and "the file is on the site".

Every image the site shows goes through a key in `content/media.ts`; today most of those keys
point at generated placeholders in `public/placeholders/`. Filling a slot means putting a file
in the right folder here, copying it into `public/images/`, and changing one line in
`content/media.ts`.

## The loop

```bash
pnpm media:check            # what is filled, what is still a placeholder, what is waiting here
pnpm media:check --import   # copy everything staged here into public/images/ and print the
                            # content/media.ts lines to paste in
```

`--import` never overwrites a file already in `public/images/` (pass `--force` if you mean to
replace one) and never edits `content/media.ts` itself — it prints the exact lines, you paste
them. Then `pnpm build` validates that every key resolves.

## Rules for files you drop

- **Names**: lowercase, hyphens, no spaces — `group-photo.jpg`, not `Group Photo (final).JPG`.
  The file name is what decides which slot it fills, so use the name each folder's README asks
  for. If you do not know where something goes, put it in `_inbox/` and say so.
- **Formats**: photos `.jpg`, UI screenshots and anything with text `.png`, flat graphics `.svg`.
  `.webp` and `.avif` work too. Next.js optimizes and resizes at request time, so drop the
  biggest clean version you have — do not pre-shrink to the display size.
- **Sizes**: each folder gives a minimum. Under it the image will look soft on a laptop screen.
- **Crops**: every slot uses `object-cover`, so the sides or the top and bottom get cut off
  depending on the screen. Keep the subject near the middle and leave a little air around it.
- **People**: only photos the club has permission to publish. Faces of people who did not agree
  to be on the site are a problem no crop fixes.

## The slots

| Folder                        | Site slot                              | Shape                | Minimum     |
| ----------------------------- | -------------------------------------- | -------------------- | ----------- |
| `home/`                       | home hero + About mission photo        | landscape, wide crop | 2560 × 1440 |
| `about/exec/<year>/`          | exec cards on About                    | portrait 4:5         | 1000 × 1250 |
| `about/instagram/`            | Instagram grid on About                | square               | 1080 × 1080 |
| `projects/<slug>/cover.*`     | project card + project page header     | landscape 16:9       | 2400 × 1350 |
| `projects/<slug>/gallery-N.*` | project page gallery + lightbox        | landscape 16:10      | 1920 × 1200 |
| `awards/<award-id>/`          | awards carousel on home and About      | landscape 3:2        | 1800 × 1200 |
| `people/`                     | testimonial and project-team avatars   | square               | 400 × 400   |
| `brand/`                      | optional brand art, social share photo | —                    | —           |

## Not needed here

- The logo, the favicon and the social share card — drawn in code
  (`src/components/brand/Logo.tsx`, `src/app/icon.svg`, `src/app/opengraph-image.tsx`).
- The dinosaur and every other pixel drawing — code, not images.
- Partner logos — the Nonprofits page draws partners as dots on a map, not as logos.
- Placeholders — generated by `pnpm gen:placeholders`, never edited by hand.
- Brand guide, fonts, Instagram source files, Framer captures — those stay in `reference/`.

Files here are ignored by git (only these READMEs are tracked): the originals live on your
disk and in OneDrive, and the copies the site serves live in `public/images/`.
