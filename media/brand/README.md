# brand/

Optional, and mostly not needed. The wordmark, the favicon, the social share card and every
pixel drawing are drawn in code — see the "Not needed here" list in `../README.md`.

What can legitimately land here:

- a photo meant specifically for link previews (a real social share image, if the generated one
  is ever not enough);
- flat brand art that a page wants to show as a picture rather than as code.

Source files — the brand guide, fonts, Instagram working files, Framer captures — stay in
`reference/` at the repo root and never ship.
