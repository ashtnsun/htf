# awards/

One folder per award, named for the award's `id` in `content/awards.ts`, with the photos
numbered in the order they should show: `1.jpg`, `2.jpg`, `3.jpg`.

Landscape **3:2**, 1800 × 1200 or larger.

A new award means a new entry in `content/awards.ts` first (id, issuer, title, date, alt text
per photo) and a folder named to match.
