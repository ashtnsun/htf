# about/exec/

One folder per board year, one portrait per member, named for the member's slug in
`content/exec.ts` (`ashton-sun-2026.jpg`, not `Ashton.jpg`).

Portrait, **4:5**, 1000 × 1250 or larger. Head and shoulders, eyes about a third of the way
down, same background and framing for everyone on a board if you can — the cards sit in a row
and mismatched crops show.

Add a folder when a new board starts (`2027-28/`), and add the member to `content/exec.ts` at
the same time — a photo with no member entry has nowhere to go.
